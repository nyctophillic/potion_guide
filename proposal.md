# Potion Guide

## Repository  
[Potion Git Repository Link :)](https://github.com/nyctophillic/potion_guide)

## Description  
This guide is an interactive program, with visuals, to aid players in making potions in the game Minecraft. It is intended to be easy to use and understand, whilst aiding the user in the brewing process, which can often be quite long and confusing.

## Features  
- Interactivity  
	- With the use of pygame, I will somehow implement an integration of mouse movements and keyboard inputs to affect the program and allow for ease of use from the user.  
- Custom Graphics  
	- Icons and graphics, custom-made, to make the process as smooth as possible. To allow for ease of use, graphics are similar to that visible in game.  
- Animations and Additional Features  
	- Added flair and interactivity throughout to create a more cohesive product. Art and animations to create a feel similar to the game and add a more personal artistic touch to polish it up.
